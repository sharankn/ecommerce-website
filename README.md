# E-Commerce Website

A full-stack e-commerce web application built using Java Spring Boot.

## Features
- Product Management
- Shopping Cart
- Checkout
- MySQL Database

## Tech Stack
Java, Spring Boot, Spring Data JPA, Hibernate, MySQL, Thymeleaf, HTML, CSS, Bootstrap, Maven

## Run

```bash
./mvnw spring-boot:run
```

Open: `http://localhost:8080`
